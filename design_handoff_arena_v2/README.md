# Handoff: Арена v2 (3D-поле Көкпар)

## Overview
Визуальное обновление игрового поля в `yessenbekov/kokpar_app`. Цель — убрать «плоский бежевый» вид: дальний туман, небо с горами, тёплый низкий свет, фактурный грунт, объёмные ворота-круг, ярусные трибуны под навесом, юрты, пыль.

## About the Design Files
`Kokpar Arena v2.html` — **дизайн-референс**, автономный three.js-прототип (three@0.184). Это не продакшн-код: задача — перенести решения в существующие модули игры (`src/game/arenaBuilder.js`, `createKokparGame.js`, `entities.js`) по их паттернам. Код прототипа можно брать кусками — он написан на том же three.js API.

## Fidelity
High-fidelity: цвета, размеры, позиции и свет — финальные. Лошади/всадники в прототипе — заглушки для масштаба, НЕ переносить (в игре свои GLB).

## Что изменить, по файлам

### src/game/createKokparGame.js — сцена и свет
- `scene.fog = new THREE.Fog(fogColor, 260, 680)` (было 82, 160 — главный источник «засвеченности»).
- `camera.far` ≥ 2000 (небо-сфера радиусом 1400, горы на 380–470).
- Убрать `scene.background = Color` → добавить небо: `SphereGeometry(1400,32,16)` с `ShaderMaterial` (BackSide, depthWrite:false, fog:false). Шейдер — вертикальный градиент `mix(horizon, top, pow(h,.55))` + мягкий ореол солнца `sunCol*(pow(s,600.)*1.2 + pow(s,24.)*.18)`, `clamp ≤ 1`. Ниже горизонта — цвет horizon. Готовый шейдер: блок «sky» в прототипе.
- Пресет «Золотой час» (по умолчанию):
  - sky top `#5f8fc4`, horizon = fog `#e8c08c`
  - sun `DirectionalLight("#ffc978", 3.6)`, position `(-150, 70, -70)`, target (0,0,0)
  - `HemisphereLight("#ffe2b0", "#8c8a5a", 1.4)`
  - `toneMappingExposure = 1.0` (ACES оставить)
- Пресет «Полдень» (опционально): top `#3f7fd0`, horizon/fog `#cfe0ec`/`#d6e0e4`, sun `#fff4dc` 3.4 at `(-70,160,-50)`, hemi `#e8f0ff`/`#9a9a62` 1.6, exposure .95.
- Тени: ortho shadow camera left/right ±130, top/bottom ±110, near 10, far 600; `bias -0.0004`, `normalBias 0.35`. mapSize 4096 на десктопе, **2048 на мобильных**.
- Убрать `fillLight` (или ≤0.3) — с небом и hemi он плоскит картинку.

### src/game/arenaBuilder.js
**createGroundDetails** — заменить линии `THREE.Line` и конусы травы на поле одной текстурой поля:
- `PlaneGeometry(WORLD.width, WORLD.height)` на y=0.04, `MeshStandardMaterial({map, roughness:.96})`, receiveShadow.
- CanvasTexture 2048×1336 (масштаб S = 2048/138 px на метр; canvas y=0 ↔ z=-45):
  1. фон `#d6ab69`;
  2. ~5200 пятен-эллипсов r 6–110px, цвета `#c99a58 #e3bd80 #bd8d4f #d9b47a`, alpha .05–.16;
  3. вытоптанность — радиальные градиенты `rgba(140,92,44,a)`: центр r36 a.28, ворота (±52,0) r18 a.22, старт серке (0,-14.5) r10 a.16;
  4. половины команд: левая `rgba(23,109,159,.07)`, правая `rgba(187,60,49,.07)`;
  5. следы копыт: 90 кривых Безье, пунктир, `rgba(112,74,36,.22)` / `rgba(240,214,160,.25)`, ширина 2–5px;
  6. орнамент «қошқар мүйіз» в центре — 4 пары завитков, `rgba(122,78,34,.32)`, линия 0.9 м;
  7. разметка мелом `rgba(250,238,205,.9)`, 0.32 м: периметр, центральная линия, круг r8.5, точка r0.8; вокруг ворот пунктир r11 и цветное кольцо r12 (alpha .55, 0.5 м);
  8. метка серке `#4fd7c8`: кольцо r3.2 + крест 5.1 м;
  9. затемнение краёв `rgba(150,104,56,.25)` на 6% сверху/снизу.
- Под полем — «вытоптанный выгон» внутри забора: плоскость (fenceX*2+6) × (northZ-southZ+6), y=0.02, текстура `#b98f58` + пятна `#a77d48 #c9a068 #9c7444`.
- Снаружи — степь: `CircleGeometry(900,64)`, текстура травы 512² `#a59c58` + пятна + штрихи, repeat 60.
- Пучки травы — один `InstancedMesh(ConeGeometry(.22,1,5), #7c8a46)`, 900 шт., **только вне забора и вне трибун**.

**createArenaEnvironment**
- Забор: две жерди (y .62 и 1.22, сечение .2×.22, `#6b4426`), столбы каждые ~4 м (`Cylinder .14/.18 ×1.6`, `#3d2819`). Угловые столбы `.32/.38 × 3.4` с золотым октаэдром r.55 (`#f0c347`, metalness .6, roughness .35) на y 3.75.
- Трибуны (север z = northZ+3 вглубь +z, юг z = southZ−3 вглубь −z): длина 116, 7 ступеней (шаг 1.15, подъём .62), `#8a6440`; задняя стенка высотой rise*7+2.6.
  - Зрители: `InstancedMesh` тело `Box .55×.8×.4` + голова `Sphere .2`, 132 в ряд × 7, 10% пустых мест, рост ×0.9–1.1. Одежда: `#26384a #7d3029 #ded1a8 #2e5f62 #b9852f #5a3a6a #e9e0cc #176d9f #bb3c31 #3f5f2a`, кожа `#c99a6e #a8774f #e0b48a #8d6040`.
  - Навес: плоскость (L+4)×(глубина+1.5) на высоте rise*7+4.7, наклон 0.14 рад, полосы 32px `#efe4cc`/`#b8442f` (repeat 5); ламбрекен .9 м над краем; 9 пар опор; флаги РК на каждой второй задней опоре.
- Табло: перекрасить в тёплую палитру — фон `#2a1a08→#140c03`, рамка `#f0c347`, «КӨКПАР» `#f7ecd0`, счёт синие `#6fc0f0` / красные `#ff8b7c`, таймер `#f0c347`, подпись «kokpar.online». Позиция (0, 17.5, northZ+18).
- Рекламные щиты: оставить, добавить сегмент `KOKPAR.ONLINE` (bg `#1a1005`, fg `#f0c347`) в каждую сторону; золотая кромка 5px сверху/снизу; материал Standard с emissive = map, intensity .12 (щиты не гаснут в тени).
- Новое: юрты (стена `Cylinder 3.4×2.4`, войлок `#efe4cc`, красный пояс `#bb3c31`, купол `Cone 3.6×2.2`, шаңырақ-тор r.7) — 8 шт. за забором: (-108,-18) (-112,4) (-104,22) (104,-30) (110,-8) (-60,-86) (-46,-92) (70,-88).
- Новое: горы — 46 конусов (7 граней, flatShading) по дуге r 380–470, высота 55–125, радиус 55–95, цвет `#9a8aa0` (полдень `#7d8aa8`); снежная шапка `#f4efe6` при h>80. Холмы — 26 полусфер r 250–320, высота 5–11, `#a29c5e`.
- Пыль: `Points` 700 шт., size .55, `#f4d9a8`, opacity .45, дрейф по +x ~1.2 м/с.

### src/game/entities.js — ворота «Круг» (createGroundGoalMesh)
R = 8 м: диск `#ead7a8` (r R−.3), внутреннее кольцо в цвет команды (opacity .45), бортик `Torus(R, .28)` в цвет команды y .2, верёвка `Torus(R,.06)` войлок y .85, 16 столбиков (каждый 4-й золотой), два флажка команды на шестах 6 м с золотыми навершиями. Тайказан — опционально, см. функцию `goal()` в прототипе.

## Interactions & Behavior
- Флаги: вершинная волна `z = sin(t*4 + x*2.2) * .12 * (x+1.3)` по 8 сегментам.
- Переключатели камеры/света/«было» в прототипе — только для демо, в игру не переносить.

## Performance
- Зрители, трава — строго InstancedMesh (2 draw call на трибуну).
- Горы/холмы/юрты: можно смержить через `BufferGeometryUtils.mergeGeometries`, castShadow выключить у гор.
- Мобильные: shadow 2048, пыль 300, зрители 90 в ряд.
