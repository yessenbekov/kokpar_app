# Handoff: горизонтальное меню Көкпар 3D + «Поделиться результатом»

## Overview
Матч идёт в горизонтали, а сейчас в вертикали `.portrait-lock` закрывает экран и просит повернуть телефон (`App.jsx:628`, `app.css:7260`). PWA-манифест уже ставит `orientation: "landscape"`. Нужно, чтобы после матча и между матчами игрок оставался в горизонтали: у каждого экрана меню должна быть горизонтальная раскладка. Плюс новый экран: карточка результата для соцсетей.

## About the Design Files
`Kokpar Menu.dc.html` — это **дизайн-референс в HTML**, не продакшн-код. Открой его в браузере (рядом лежат `support.js` и `art/`). Нужные разделы — **12** и **13**, у каждого экрана есть id-бейдж (12a…13h). Реализовать нужно в существующем стеке репозитория: React и `src/styles/app.css` с его классами и токенами, тексты через `t(ru, kz, en)`.

## Fidelity
**High-fidelity.** Цвета, шрифты, отступы и тексты финальные. Если в app.css уже есть класс с похожим видом, используй его и подгони значения.

## Общие правила горизонтали
- Медиазапрос: `@media (orientation: landscape) and (max-height: 520px)`.
- Макетный экран 844×390. Отступы: слева 52px (вырез камеры: `max(52px, env(safe-area-inset-left) + 16px)`), справа 30px, сверху 18px, снизу 20px.
- Вертикальной прокрутки нет: длинный список превращается в колонки или сетку карточек.
- Заголовок и «‹ Назад» (38×38, radius 10) стоят слева сверху, главная кнопка — справа или снизу справа (под большим пальцем). Высота кнопок от 48px.
- Сетки только через `minmax(0,1fr)`, чтобы ничего не вылезало.

## Design Tokens
- Фон экрана: `linear-gradient(165deg,#2e1c08,#150c03)`. Панель: `rgba(52,32,10,.62–.85)`, border `rgba(190,148,60,.22–.3)`.
- Текст `#f2e2b8`, заголовки `#f7ecd0`, вторичный `rgba(214,178,110,.75)`, золото `#d0a030` / `#f0c347`.
- Синий (основное действие и команда Көк): `#3aabee→#2590d0`, светлый `#7ec8f0`. Красный (Қызыл): `#e04535`, светлый `#f3a196`. Зелёный (онлайн/готов): `#6fd39a`.
- Шрифты: Oswald 600/700 для заголовков и кнопок (uppercase, ls .05–.08em), Manrope 400–800 для текста. Подписи над группами: 10–11px/700, ls .12em, uppercase.
- Радиусы: кнопки 11–12, карточки 13–16, чипы 6–8, pill 999.
- Тень основной кнопки: `0 6px 20px rgba(37,144,208,.35)`.
