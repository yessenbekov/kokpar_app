# Kokpar 3D — меню v2 «Эфир»

Новый визуальный стиль меню в духе спортивной трансляции. Макет: `Kokpar Menu v2.dc.html` (открыть в браузере). Скриншоты: `screenshots/` (L = горизонталь 844×390, P = вертикаль 390×844).

## Принципы
- Жёсткие углы: `border-radius: 0` у всех панелей и кнопок. Скругления только у рамки телефона.
- Скошенные плашки: `clip-path: polygon(12px 0,100% 0,calc(100% - 12px) 100%,0 100%)` для главной кнопки, у заголовков-«лент» скошен только правый край.
- Золотым выделено только главное действие на экране. Синий и красный — только цвета команд.
- Цифры как на табло: Oswald 700, `font-variant-numeric: tabular-nums`.
- Названия и подписи — Oswald КАПСОМ с letter-spacing .08–.14em, мелкие пояснения — Manrope.

## Общие элементы
- **Шапка экрана**: квадрат «‹» 36×32 + золотая лента с заголовком (Oswald 15/700). Справа: шаг «ШАГ 1 / 2» или монеты (золотая плашка).
- **Главная кнопка**: золото, скос 14–16px, текст слева, «▶» справа. Высота 52–80px.
- **Вторичная кнопка**: прозрачная, рамка 1px rgba(255,255,255,.22).
- **Опасная кнопка**: рамка #e04a3a 70%, фон 12%, текст #ff8a7a.
- **Сегменты настроек**: строка-«табло» (подпись слева 96px), выбранный сегмент — золото.
- **Табло счёта**: синий блок | белая цифра | бежевая цифра | красный блок.
- **Бегущая строка** (главный экран): высота 30px, лента «ЖАҢАЛЫҚ» + новости через ◆. Анимация translateX, ~40 px/с, пауза при `prefers-reduced-motion`.

## Шкала характеристик лошади (экран 4)
`значение = round(коэффициент × 70)`. Для staminaDrain берётся обратное: `round(70 / staminaDrain)`.
Ширина полосы: `(значение − 40) × 4` px в горизонтали, вдвое меньше в вертикали. Золотым подсвечено значение, которое лучше, чем у соперника.

## Данные
Режимы — `gameModes.js`, лошади — `horseTypes.js`, снаряжение и цены — `shopItems.js`, настройки — `matchConfig.js`, итоги — поля `reward` из `MatchReward.jsx`. Имена игроков, код комнаты и счёт в макетах — примеры.
